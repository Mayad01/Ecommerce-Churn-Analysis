E-Commerce Churn Analysis & Retention ROI Optimization :
An analytical project focused on customer churn prediction and analysis for an E-Commerce platform, involving
ETL processes and Data Warehouse (DWH) architecture design. Developed Tableau dashboards and applied data
mining models to investigate behavioral patterns and proactively identify at-risk customers. The primary focus
was translating raw data into actionable business strategies by defining ROI metrics and delivering targeted
insights to optimize customer retention efforts.
